# 数据目录、读取预设与任务

先区分三个对象：

| 对象 | 保存什么 | 例子 |
| --- | --- | --- |
| 数据集 | 原始数据入口、已有产品入口和载荷标签 | 共享目录中的 14B 数据与 14B 历史产品 |
| 读取预设 | XML、字段换算、文件规则、源能线和分析 YAML 的可复用配置 | `15B cali_proc 0.5` 的某个版本 |
| 任务 | 一次独立分析的配置快照、窗口、TB 依赖、运行记录和结果 | 为 Co60 双峰复核创建的一份任务 |

“新建任务”建立一份独立分析任务。“新规范回归”“Co60 双峰 v2”是已有任务的人为名称；实际采用的读取预设和版本，需要到“解包与读取设置”中查看。同一个预设版本可以用于多份任务。

## 1. 选择数据与已有产品

点击顶部 **选择数据 / 产品**。

在窄屏窗口中，**选择数据 / 产品**、**解包与读取设置**和**参考能谱**收在顶部 **工具** 菜单内。

1. 在“原始数据目录”填入服务器上的采集目录。例如 14B 使用 `/lime/GRID/calibration/cali_data/raw/14B`。
2. 若要载入已有分层结果，在“产品目录”选择对应载荷的产品根，例如 `/lime/GRID/calibration/cali_data/14B`。这个目录用于读取已有结果，当前任务的输出会另存到个人工作区。
3. 点击“扫描并识别”，再从“数据集”选择所需载荷。展开“目录详情”核对实际路径。
4. 核对“载荷编号”。它决定新输出的载荷标签；原文件所在位置仍由目录和文件映射确定。

扫描优先载入所选目录关联的预设版本；未关联目录时，按载荷匹配个人预设库。若匹配到多个版本，在“读取配置”和“版本”中明确选择后创建任务。

使用准备命令配置过的工作区，可点击“默认目录”恢复共享入口。也可以在“已保存的目录”中选择记录并点击“载入”；“管理目录记录”用于保存当前数据目录，方便下次直接选用。

只填写 raw 或产品目录时，扫描会尝试从默认的另一类目录中按载荷名称配对；在“目录详情”查看最终登记的两侧路径。若数据集实际只有 raw，从 EXP/L0 开始；若只有产品，可查看或处理已有上游结果，L0 解包需补充对应原始数据。

数据目录登记整批来源；进入具体处理层后，也可以在输入栏单独选择所需上游结果。

### 为某一层选择输入

1. 在要计算的层点击输入栏 **更换**，例如 TB L2 的“TB L1”行。
2. 选择 **共享产品 / 当前任务 / 其他任务**。共享产品来自登记的产品目录，其他任务来自当前工作区同一物理载荷的已保存任务。
3. 核对所选结果的生成时间、文件与通道范围。“文件与配置”可展开查看文件名和路径。
4. 默认选用整批；局部替换时展开 **选择文件与通道**。
5. 查看 **更新范围**，点击 **应用** 保存输入选择，或 **应用并更新** 继续计算。

TB L1 读取 L0，TB L2 读取 L1；EC corr 读取 EC L0 和 TB L2，EC L1 读取 corr，EC L2 读取能峰结果。选择原始事件与 HK 仍从 EXP/L0 的数据目录入口完成。

有读取权限的个人产品目录也可从 **选择数据 / 产品** 登记为来源；“其他任务”只列出当前工作区中的任务。

在“当前任务”选择 **使用本任务上游结果**，连接本任务当前上游。指定共享或其他任务的结果时，保存这份具体输入。各层输入与结果复用的完整操作见[分层输入指南](https://github.com/Lee-Eee-Eee/GRID_Calibration_Lab/blob/feat/calibration-workbench/docs/layer_inputs.md)。

### 路径写在哪里

工作台运行在服务器时，目录输入框和“浏览”显示的都是服务器文件系统。

| 入口 | 应选择的位置 |
| --- | --- |
| 原始数据目录、产品目录 | 服务器目录，或个人工作区中指向该目录的软链接 |
| XML 路径输入框后点击“读取” | 服务器上可访问的 XML 路径 |
| XML 的“选择 XML”按钮 | 本地浏览器可选择的 XML 文件，文件内容载入编辑器 |
| TB L2 参数包路径 | 服务器上的 JSON 参数包路径 |

例如原始数据在服务器 `/lime/...` 下，就使用该路径；浏览器所在电脑的 `C:/...` 不是服务器目录。

## 2. 继续已有任务，或新建一份

选定数据集后，若个人索引中已有同一来源的结果，“已有任务”会列出这些任务及其配置版本。

- **继续处理**：选择所需任务，点击“继续”。恢复其当前结果、窗口和依赖。
- **另做一次分析**：核对载荷、读取配置与版本，填写能说明本次工作的任务名称，点击 **创建任务并载入**。

新任务会固定所选配置快照，并载入所选产品中可用的结果，作为分析起点。随后所有计算写入自己的 `runs/<run_id>/`。同一批原始数据可以对应多份个人任务。

顶部“任务”下拉框也能切换当前载荷的已保存任务。切换任务不会等于应用新的读取预设。

## 3. 核对读取配置

打开顶部 **解包与读取设置**。先从“读取配置”和“版本”确认当前来源。

| 按钮 | 作用 |
| --- | --- |
| 载入编辑 | 将所选预设版本放入编辑器，继续修改草稿 |
| 应用此版本 | 将所选版本直接用于当前任务 |
| 从模板新建 → 载入模板 | 从内置协议模板建立草稿 |

配置分为四页：

### XML 与字段

分别设置“事件包 XML”和“遥测包 XML”。可以采用内置 XML、选择 XML 文件、读取服务器路径，或直接编辑 XML 内容。

检查事件 / HK 的包标签和字节序，再核对通道、幅度、基线、时间戳、温度和偏压字段。温度、偏压字段名可使用 `{channel}` 对应各物理通道。需要修改比例、偏移、分压与电流压降时，展开“原始量换算与多包读取参数”。

### 文件与工况

选择温度与偏压的读取方式：

- **遥测 HK**：从实际遥测换算并选择稳态工况；14B / 15B 确认配置采用此方式。
- **文件名**：从已配置的文件表达式中提取标称工况。
- **逐文件映射**：使用映射行中填写的温度 / 偏压。
- **固定值**：该配置中的采集都采用给定工况。

HK 工况以实测数据为准。文件名中的 `m20`、`285` 等标签可帮助识别文件，但不会自动替代 HK 的物理量。

文件发现有两种形式：

| 方式 | 适合情况 | 需要填写 |
| --- | --- | --- |
| 文件名规则自动匹配 | 同批采集使用稳定命名 | 子目录、事件 / HK 正则、配对键和物理标签的命名组 |
| 逐文件映射表 | 文件名变化，或需要明确列出配对 | Event / HK 相对路径、类别、通道、能量、源、工况等 |

正则命名组可提取 `key`、`energy`、`channel`、`source`、`exposure`、`unit`，工况表达式可提取 `temp` / `bias`。映射路径可相对于当前原始数据目录填写。

映射表可逐行添加，也可粘贴 CSV / TSV。常用列名如下：

```text
event,hk,kind,channel,energy_keV,peak_energies_keV,source,exposure_minutes,temp,bias
```

`kind` 取 `tb`、`xray`、`source` 或 `background`。多个源能线用逗号分隔，放入 CSV 单元格时需加引号；未知的可选物理量留空。

本页的“放射源能线”表保存源名称、文件名别名和可能能线。实际谱上的 ADC 窗口与逐峰操作见[EC 标定](https://github.com/Lee-Eee-Eee/GRID_Calibration_Lab/wiki/EC-Calibration)。

### 分析配置

14B / 15B 的新规范配置包含四份 YAML：

| 文件 | 调整内容 |
| --- | --- |
| `tb_l1.yaml` | TB 选段、谱范围、分箱和逐通道峰窗 |
| `tb_l2.yaml` | 温偏曲面拟合设置 |
| `ec_l1.yaml` | EC 选段、信号 / 本底配对、能线、峰窗与谱模型 |
| `ec_l2.yaml` | 能量关系、分段和分辨率拟合设置 |

初次建立新规范草稿时，选择配置载荷并点击“载入配置与文件表”。它会载入仓库确认文件表与分析配置；之后在编辑器中修改所需项目。

共享目录中的 `raw/14B`、`raw/15B` 与确认文件表配合使用。早期采集目录的 `02` / `03` 名称与当前载荷标签并不相同，使用确认映射，不按旧目录名称自行猜测载荷。

### 检查配对

点击 **预览与校验**，在“检查配对”页核对：

1. Event 与 HK 是否配成同一采集。
2. TB / X 射线 / 放射源 / 本底类别是否正确。
3. 物理通道、能量、源名称和工况是否正确。
4. 信号与本底文件是否符合本次实验配对。

修改草稿后，再次预览当前版本。对 14B / 15B 新规范，曝光来自所选物理通道的原生事件时钟计数器跨度；文件名中的分钟数用于识别观测，不作为实际归一化曝光。

## 4. 保存和复用预设

检查配对后，有三种保存方式：

| 操作 | 保存到哪里 | 用途 |
| --- | --- | --- |
| 填写“修订说明”，点击“保存读取配置” | 当前任务的配置快照 | 只在这份任务中调整读取方式 |
| “另存为新预设” | 个人预设库，并应用于当前任务 | 建立一份可在其他任务复用的独立配置 |
| “保存为新版本” | 当前预设的下一版本，并应用于当前任务 | 保留同一预设的修订链 |

检查配对后，展开 **保存配置版本**：

1. 填写“预设名称”和“所属载荷”。
2. 决定是否勾选“自动关联当前数据、产品目录”。勾选后，下次选择相同目录会优先匹配该预设版本。
3. 点击“另存为新预设”，创建独立的预设；要在当前预设上保留修订链，点击“保存为新版本”。

旧版本会保留。新版本发布后，已有任务仍使用各自的固定快照；要让某份任务采用新版，在该任务中选择新版本并点击“应用此版本”。

修改配置后，**预览与校验** 会显示 **更新范围**，按实际变化列出文件、通道和处理层。保存后可点击主区的 **更新受影响层**。例如，只改 EC 分段边界更新 EC L2；修改一个 TB 峰窗更新相应 L1 与曲面。名称、备注或图表显示变化不需要重新解包。

顶部“保存修订”用于本任务的窗口、屏蔽等分析调整；EC 源谱页的“保存配置”用于该任务的能线与 ADC 表。需要把源模型等分析设置长期复用于新任务时，在读取配置的分析 YAML 中保存，并发布预设版本。

预设版本号只在同一份预设内递增。不同成员分别建立的 `v2` 不一定是相同内容；记录实验时同时写明预设名称、版本和所用任务。

15B Co60 的双峰修订需要在自己的工作区建立对应配置版本。详见[EC 标定](https://github.com/Lee-Eee-Eee/GRID_Calibration_Lab/wiki/EC-Calibration)中的 1173.228 / 1332.492 keV 联合拟合步骤。

## 5. 读取预设与 TB 参数分别选择

读取预设规定“如何读这些文件、如何选段、如何拟合”。EC 所用的 TB L2 参数包规定“按哪套温偏响应校正”。这是两个独立选择。

在 EC corr 页的 **TB L2 → 更换** 中选择参数版本并应用；也可点击侧栏 **导入 TB 参数包**，填写服务器上的 JSON 路径。可以使用已有 TB 包，不必在本任务先跑 TB L2。

指定 TB 版本后，本任务重新拟合 TB 不会替换该包。如需跟随本任务曲面，在“当前任务”选择 **跟随本任务 TB**。更换 TB 后更新 corr 与使用它的后续拟合；发布读取预设的新版本不会替换固定的 TB 包。

## 6. 找到自己的结果

在个人工作区查看：

```text
workspace/runs/<run_id>/
├── state.json            # 任务及当前处理状态
├── acquisition/          # 读取配置快照、XML 和四份分析 YAML
├── inputs/               # 选定产品引用、文件清单及适配输入
├── dependencies/         # 选定 TB 参数包
├── revisions/            # 保存的窗口、屏蔽和配置修订
├── peak-config/          # 本任务的源能线与 ADC 配置
├── products/             # 当前产品
└── jobs/                 # 每次计算的配置、日志和产物
```

界面的“文件与运行记录”提供文件名和预览；日常复核可直接从这里找到 JSON、图和运行日志。具体操作见[复核与结果](https://github.com/Lee-Eee-Eee/GRID_Calibration_Lab/wiki/Review-and-Results)。
