# TB：温度—偏压标定

TB 标定使用同一入射能峰在不同温度、偏压下的峰位，拟合探测器增益响应。本页按当前 14B / 15B 的新规范界面说明：**EXP/L0 → L1 → L2**。

开始前，在左侧选择载荷，在顶部选择本次要继续的任务。任务保存这一轮的配置快照、窗口、屏蔽点、结果和计算记录；同一载荷可以有多份任务。目录选择与新建步骤见 [数据、预设与任务](https://github.com/Lee-Eee-Eee/GRID_Calibration_Lab/wiki/Data-and-Presets)。若刚建好任务，先用一个工况跑通，再处理全部工况。

## 1. 解包一个工况

1. 点击 TB 下的 **EXP/L0 · 原始解析**。
2. 在“数据来源”确认当前服务器数据目录；在“解包设置”确认读取预设。
3. 在“选择输入文件”中搜索并选定一对事件 / HK 文件。下方显示所选文件路径。
4. 点击 **解包选中文件**。
5. 完成后，主图显示当前通道的脉冲谱，右侧显示文件信息和事件统计。展开 **文件与运行记录 → 运行记录**，可查看这一任务的输入、状态、输出文件和日志。

左侧“分析通道”切换 CH0–CH3。解包读取该文件的事件；图中谱和后续单点拟合对应当前选择的物理通道。

需要处理整批数据时，点击 **批量解包…**，核对确认框列出的范围，再开始解包。搜索框用于找文件，批量操作的范围以确认框为准。

EXP 保存解包后的事件与工程字段，L0 保存供标定使用的清洗数据。14B / 15B 使用原生 SCI 计数时间和独立 HK 选段；工况详情中的实测温度、偏压来自 HK 平台，不等同于文件名里的标称值。

## 2. 查看 L1 谱与拟合

1. 点击 **L1 · 能谱峰拟合**。切层后保持当前工况和通道。
2. 从“工况文件”列表选择文件。可按文件名、温度或偏压搜索，并筛选已有拟合、需检查或待拟合的文件。
3. 查看主谱、拟合曲线、背景和下方逐 bin 残差。
4. 查看右侧的峰位及误差、σ、约化 χ²和模型。通道卡可以快速切到同一工况的另一个通道。

“上一个 / 下一个”沿当前筛选结果切换文件，保留通道。谱图工具栏支持框选缩放、平移和重置；主谱与残差横轴联动。

展开 **拟合质量**，可按实测温度和偏压查看当前通道的全部工况。点击地图中的点，会选中对应文件并载入它的真实谱；收起地图后，质量统计仍保留在标题行。

### 手动拖窗并重拟合

1. 在主谱中拖动蓝色 **下限 / 上限** 边界，或在“拟合窗口 ADC”输入精确数值。
2. 确认范围覆盖目标峰及足够的邻近背景。界面标为“窗口已修改”时，已有曲线仍是上一次拟合结果。
3. 点击 **按当前窗口拟合**。顶部的 **拟合当前窗口** 执行同一当前通道操作。
4. 等待结果反馈，检查更新后的曲线、峰位误差和残差。

默认只重拟合当前文件、当前通道。**拟合此文件 · 四通道** 用于该文件全部可拟合通道。拖窗手柄也支持左右方向键微调，按住 Shift 增大步幅；输入框显示三位小数，未编辑的值仍按保存的完整精度使用。

### 自动选窗

展开 **自动选窗**，点击 **自动选窗并拟合**，处理器会重新推荐窗口并实际拟合。靠近暗噪声时，可以填写实测的“噪声上界 / ADC”或独立已知的“期望峰位 / ADC”。这两个量都使用当前谱的 ADC 单位。

自动选窗和手动拟合是两个入口：自动入口会重新选择窗口；手动入口使用图中当前窗口。候选峰与选择依据可在 **寻峰候选与拟合证据** 中查看。

### 处理全部工况

在顶部“计算范围”选择 **全部数据**，点击 **运行本层全部数据**。这会处理配置覆盖的全部工况及适用通道。批量任务按文件、通道保存结果；若有部分失败，先从“需检查”列表查看对应谱，已完成结果仍保留。

14B / 15B 当前默认分箱为 4 ADC/bin，实际 bin 宽显示在谱区。不同载荷可以使用不同分箱。窗口最小宽度随实际 bin 宽变化，不能把另一套分箱下的窗口数值直接当作同一范围。

## 3. 计算 L2 温偏曲面

1. 完成需要纳入的工况 L1 拟合。
2. 点击 **L2 · 曲面拟合**，或在 L1 页点击 **计算 TB L2**。
3. 点击 **运行本层** / **重新拟合 TB**，计算当前有效点对应的温偏曲面。
4. 在右上角切换 **峰位 + 残差连线** 和 **三维残差**。
5. 查看各工况残差，以及“参数比较”中的 G₀、k、V₀、b、c 和拟合诊断。

模型为：

```text
G(T,V) = G₀ · (V − kT − V₀)² · (−T² + bT + c)
```

点击三维图或残差图中的实测点，可查看该工况、该通道的 L1 谱和拟合参数。若需要修改峰拟合，回到 L1，完成重拟合后再计算 L2。

### 屏蔽、恢复与比较

1. 在曲面或残差图选择要复核的点。
2. 记录原因，点击 **屏蔽此点**。
3. 点击 **重新拟合 TB**，查看新曲面和参数变化。
4. 如需恢复，重新选中该点，点击 **恢复此点**，再计算一次 TB。

屏蔽决定是否使用该点，拟合质量提示帮助判断谱和模型是否相符。“疑似问题”本身不会停止后续拟合；应结合谱形、残差和物理工况决定是否屏蔽。

## 4. 保存本轮结果

点击顶部 **保存修订** 记录窗口、屏蔽点及说明。计算任务会保存实际生成的结果文件；保存修订不会代替拟合或曲面计算。重新打开同一试算，可继续原来的处理层、通道和文件。

新规范的 TB L1 分析包包含 `meta.json`、按通道组织的 `points.json`、`spectra.parquet` 及拟合 / 选段图；TB L2 生成时间戳参数包和图。实际文件位置在 **文件与运行记录** 中查看。

接下来可将本次 TB L2 参数包用于 [EC 能量标定](https://github.com/Lee-Eee-Eee/GRID_Calibration_Lab/wiki/EC-Calibration)，也可在 EC 中选择其他时间已经生成的 TB 包。
