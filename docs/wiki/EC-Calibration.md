# EC：能量刻度与分辨率

EC 用已知能量的 X 射线或放射源峰建立校正 ADC 到能量的关系。当前 14B / 15B 新规范界面按 **EXP/L0 → corr → L1 → L2** 操作。

| 界面步骤 | 计算内容 | 得到什么 |
| --- | --- | --- |
| EXP/L0 · 原始解析 | 解包 X 射线、放射源和本底采集 | 事件、HK 和清洗谱输入 |
| corr · 温偏校正 | 使用选定 TB L2 参数校正温偏 | 校正 ADC 谱及 TB 依赖 |
| L1 · 能线峰拟合 | 拟合一张谱中的一个或多个已知能峰 | 峰位、误差、宽度、拟合曲线 |
| L2 · 能量标定 | 由各能线的峰位及误差拟合刻度与分辨率 | 分段能量模型和分辨率模型 |

旧任务及内部任务编号中，EC L1 / L2 / L3 分别对应这里的 corr / L1 / L2。教程后文均使用当前新规范界面的名称。

首次在自己的个人工作区处理 15B Co60 时，先按本页“15B Co60 联合双峰”小节建立自己的配置新版本，再计算 EC。服务器准备工具载入的是内置原始确认配置，其他成员个人工作区中的双峰版本不会自动复制过来。

## 1. 选择校正用的 TB 参数包

进入 **corr · 温偏校正**，在主区输入栏点击 **TB L2 输入选择框**。从 **共享产品 / 当前任务 / 其他任务** 选择所需结果，查看“更新范围”，点击 **应用**，或 **应用并更新**。

也可以在选择侧栏点击 **导入 TB 参数包**，填写服务器上已有 TB L2 JSON 的完整路径，点击 **导入并采用**。例如：

```text
/home/your_name/calibration-workbench/workspace/runs/<run_id>/products/14B/tb/L2/<timestamp>/<model>.json
```

参数包也可以来自共享产品目录或其他有读取权限的目录。工作台会固定选定包的快照，EC 并不要求先在当前任务重新计算 TB L2。

要随本任务的温偏曲面更新，在“当前任务”选择 **跟随本任务 TB**。固定版本时，本任务 TB 重算不会替换 EC 已选的包。

**载荷读取预设版本与 TB 参数版本是两件事。** 读取预设决定如何读文件、换算字段和拟合；TB 参数包决定此次 EC 使用哪组温偏校正系数。两者都应在开始计算前确认。

## 2. 跑通一个 X 射线文件或源谱

### 分层执行

1. 在 **EXP/L0 · 原始解析** 选择事件 / HK 文件，点击 **解包选中文件**。
2. 对放射源，还需解包读取配置中对应的本底文件。
3. 进入 **corr · 温偏校正**，确认已采用所需 TB 参数，选定文件，点击 **校正当前文件**。源谱和本底都要采用同一目标 TB 校正条件。
4. 进入 **L1 · 能线峰拟合**，选择通道及能线，检查真实校正谱。
5. 调整窗口后点击 **按当前窗口拟合**，查看峰位、误差、模型和残差。

### 使用流程预览

也可以在当前谱展开 **右上角 ⋯ → 运行代表闭环**，选择当前文件并核对步骤。EC 源谱预览会列出源与本底所需的解包、校正和峰拟合步骤，再开始执行。此入口适合首次跑通一张谱。

X 射线本底配对来自载荷文件表或读取配置。14B / 15B 新规范按下一照射槽位取本底文件，再从该文件选择与信号相同的物理通道；调整配置时同时检查信号与本底的文件、HK 和通道。

已有 EC L0 或 corr 时，可通过下一层的输入选择框更换上游来源；默认选整批；corr 页通过 **选择文件** 限定范围，L1 峰拟合页可通过 **选择文件与通道** 限定范围。直接复用本层能峰或刻度时，使用 **右上角 ⋯ → 采用已有结果…**。操作见[分层输入指南](https://github.com/Lee-Eee-Eee/GRID_Calibration_Lab/blob/feat/calibration-workbench/docs/layer_inputs.md)。“其他任务”来自当前工作区；其他成员的产品也可通过数据目录入口登记为来源。

14B / 15B 信号、本底分别按原生事件计数的实际跨度归一化，文件名里的“5m”“30m”等文字不作为此次计算的曝光秒数。拟合详情会显示主谱与本底各自的曝光。

## 3. 调整一个峰

在 **L1 · 能线峰拟合** 页：

1. 通过“能线 / 源峰”选择目标能线，或按文件名、能量搜索。
2. 拖动蓝色窗口边界，也可输入 ADC 下限、上限。
3. 点击 **按当前窗口拟合**。
4. 先看峰位、σ 和误差是否合理，再看目标峰与背景是否贴合、逐 bin 残差是否有连续结构。

本次操作只更新当前观测、当前通道、当前能线。切换能线或通道不会把刚才的窗口套到所有点。需要更新能量刻度时，完成峰拟合后进入 L2 重新计算。

默认谱区显示净计数率密度，14B / 15B 当前使用 4 ADC/bin；误差包含信号与本底的计数、曝光和 bin 宽传播。净谱可能出现负 bin，局部谱视图因此保留线性纵轴。

## 4. 一张放射源谱拟合多个峰

点击右侧 **能线配置**，在弹窗中选择 **源谱文件**。工作台结合预设、文件名中的源名称和谱元数据预载能线；表中每行是一条能线在当前通道的 ADC 配置。

| 字段 | 填什么 |
| --- | --- |
| 能量 / keV | 已知入射能线能量，例如 Na22 的 511.004、1274.5 keV |
| ADC 下限 / 上限 | 当前通道该峰的拟合窗口 |
| 期望 ADC | 可选的独立峰位参考，用于帮助区分目标峰 |

1. 用 **增添能线** 添加需要分析的峰，输入能量。
2. 点击该行 **查看**，在真实谱上选择窗口；也可直接编辑表格。
3. 点击 **显示整张谱** 查看各能线在同一张谱上的位置，再用 **聚焦当前峰** 返回局部视图。
4. 点击 **保存配置**，保存本任务的能线、各通道窗口和中心锚。
5. 点击 **拟合全部能线**，拟合当前源谱、当前通道的全部已配置能线。只想更新一条时，使用右侧 **按当前窗口拟合**。
6. 切换通道，为其他通道分别检查、配置和拟合。

“移除”将能线移出本次源谱配置。重新计算 L2 能量关系后，刻度使用当前活动能线。该表的 **保存配置** 保存任务内的多峰编辑；要供后续新任务复用，应在“解包与读取设置 → 分析配置”的 `ec_l1.yaml` 中填写相应能线、窗口与模型，再发布读取预设的新版本。

### 15B Co60 联合双峰

15B 这批 Co60 的左、右峰分别是 **1173.228 和 1332.492 keV**。内置原始确认配置保留了早期单峰窗口，其中左峰曾被标成 1332.492 keV。双峰方案在覆盖两峰的窗口内拟合“双高斯＋线性本底”：两个中心独立拟合，每条能线保存自己的结果，并保留联合拟合的协方差。

在自己的个人预设中建立这套方案：

1. 打开 **解包与读取设置**，选定本次使用的 15B 预设和版本。
2. 进入 **分析配置**，在 `ec_l1.yaml` 找到 `source.Co60`。保留事件、HK、本底、选段和曝光配置；将原 `background` / `fit_range` 替换为下列值，新增 `fit_mode` 与 `peaks`，删除该条目旧的单值 `energy_keV` 和 `window_guard`。
3. 执行 **预览与校验**，检查两条源能线及文件配对。
4. 展开 **保存配置版本**，填写说明并点击 **保存为新版本**。如果这是另一套独立方案，也可 **另存为新预设**。详细操作见 [数据、预设与任务](https://github.com/Lee-Eee-Eee/GRID_Calibration_Lab/wiki/Data-and-Presets)。
5. 在采用这个新版本的任务中，选择所需 TB 包，依次运行 **EC L0 → corr → L1 → L2**。已有产品也应按界面显示的待更新层重新计算。

Co60 条目的核心结构为：

```yaml
source:
  Co60:
    fit_mode: doublet
    background: lin
    fit_range: [[5800, 8500], [6449.6, 9452], [5858, 8585], [6722.2, 9851.5]]
    peaks:
      - energy_keV: 1173.228
        center_anchor: [6713, 7440, 6761, 7769]
      - energy_keV: 1332.492
        center_anchor: [7695, 8524, 7748, 8893]
```

四个数组槽位依次对应 CH0–CH3。上述窗口与中心是当前 15B 这批数据的配置示例，其他采集应根据各自的校正谱确定。每个成员的版本号由自己已保存的版本数量决定，不要求一律叫 v2。

使用联合双峰策略时，拟合窗口必须容纳两个独立中心锚；把窗口缩到只剩其中一峰，已不符合这套模型的输入要求。

## 5. 计算能量关系与分辨率

1. 确认要使用的各能线均有当前 TB 版本下的校正与峰拟合结果。
2. 进入 **L2 · 能量标定**，点击 **运行本层** 或 **计算 EC L2**。
3. 主图显示实测 ADC—能量点与拟合曲线，默认 **双对数坐标**。可切换 **线性坐标**，刷新后保留选择。
4. 下方用“EC 诊断量”切换 **刻度残差** 和 **能量分辨率**。残差纵轴始终保留正负线性数值。
5. 点击高残差点，可在右侧查看对应文件、通道、能线的真实谱和拟合参数。

当前 14B / 15B 使用分段 ODR `E=f(ADC)`，固定已知能量、采用 ADC 峰位误差。分段边界读取 `ec_l2.yaml`；现行默认低能为 E < 51 keV，高能为 E ≥ 55 keV。间隔中的能线仍可在 L1 复核，但不进入这两段刻度拟合。两段曲线只在各自实测 ADC 范围绘制，段间留断点。

若屏蔽或恢复一个能峰，重新计算 **EC L2** 后查看刻度变化。若修改的是某个峰的窗口，则先回 L1 重拟合该峰，再计算 L2。

## 6. 更换 TB 版本后怎样继续

在 corr 的 **TB L2 输入选择框** 中选择新包，核对更新范围后点击 **应用并更新**；若只点“应用”，稍后点击 **更新受影响层**，或依次运行 **corr → L1 → L2**。需要全量刻度时，确认范围覆盖所需全部观测和物理通道。已选的读取预设不会因此自动换成别的版本。

展开 **能峰文件的 TB 依赖与来源** 或谱区的 **谱文件与 TB 依赖溯源**，可查看各源、本底和峰结果使用的 TB 文件。读取来源不完整或上下游尚未更新时，任务会指出需要先运行哪一步。
