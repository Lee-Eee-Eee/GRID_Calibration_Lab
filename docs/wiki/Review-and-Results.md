# 复核、保存与结果查找

一次复核从确认“正在看哪份数据”开始：顶部载荷和任务、当前层工具栏的通道，当前处理层，以及右侧工况 / 能线选择应共同对应目标观测。还未建立个人任务时，先按 [数据、预设与任务](https://github.com/Lee-Eee-Eee/GRID_Calibration_Lab/wiki/Data-and-Presets) 操作。

## 任务、预设和版本分别是什么

| 对象 | 含义 | 常见操作 |
| --- | --- | --- |
| 任务 | 一轮独立的配置快照、窗口、屏蔽点、结果和日志容器 | 新建、继续、局部重算、比较结果 |
| 读取预设 | 可供多个任务复用的 XML、字段换算、文件规则、源能线及分析配置 | 另存为新预设、保存为新版本 |
| 预设版本 | 同一预设的一份具体快照，例如 v1、v2 | 新建时选定，或主动切换已有任务 |
| TB 参数包 | EC 校正使用的一份 TB L2 模型 | 选择版本、导入并采用 |
| 作业 / 运行记录 | 一次实际调用处理器的请求和结果 | 查看范围、输入、配置、耗时、文件与错误 |

“新规范回归”“Co60 双峰 v2”等是已有任务的名称，用于描述当时处理目的；“新建任务”用于建立新的分析任务。名称本身不决定算法或输入，具体采用的预设、版本、TB 包和范围应在当前任务中查看。

## 输入、采用结果与预览

| 操作 | 用途 |
| --- | --- |
| 输入选择框 | 选择本层要读取的上游；本层及使用它的下游待更新 |
| **结果 → 采用已有结果…** | 直接使用一份本层结果包，本层无需再算；下游按新结果更新 |
| 运行记录中展开 JSON、图片或日志 | 查看已有文件，保持输入选择不变 |

例如，在 TB L2 更换一份 L1 输入后，需要重新计算曲面；采用一份已有 TB L2 则可以直接查看和使用该曲面。

输入选择侧栏提供 **共享产品 / 当前任务 / 其他任务**，选中后可展开“文件与配置”。**更换输入**时还可通过“选择文件与通道”局部替换；采用已有结果按所选结果包进行。操作说明见[分层输入指南](https://github.com/Lee-Eee-Eee/GRID_Calibration_Lab/blob/feat/calibration-workbench/docs/layer_inputs.md)。

## 如何读谱与残差

### TB L1 / EC L1 谱拟合

谱图显示实测数据、总拟合曲线和背景；右侧显示峰位及误差、σ 和模型。新规范用约化 χ²帮助判断计数误差下的模型一致性，旧任务也可能显示 R²。

下方逐 bin 标准化残差用于定位模型没有解释的结构。随机分散的残差和连续偏离的残差含义不同：持续同号、峰两侧系统性波动或第二个峰，通常应回到窗口、背景或峰模型检查，而不是仅追求一个较高的 R²。

“疑似问题”结果保留数值参数，可继续下游拟合。使用者可以在看谱后决定屏蔽或恢复。数值计算失败与模型待定的点会单独显示。

### TB L2 与 EC L2 总览

- TB 可切换 **峰位 + 残差连线 / 三维残差**，检查温度、偏压方向上是否有系统趋势。
- EC 主图默认双对数，便于同时查看低能和高能点；下方切换刻度残差与分辨率。
- 主图和残差图中的实测点均可点击下钻。检查当前通道，避免把不同通道的 ADC 窗口或峰位混为同一个结果。

## 保存与计算是两个动作

| 操作 | 保存什么 | 会不会计算 |
| --- | --- | --- |
| 顶部 **保存修订** | 当前窗口、屏蔽点和修订说明 | 不代替拟合或标定计算 |
| 源谱区 **保存配置** | 当前任务的能线、通道窗口和中心锚 | 不重拟合谱 |
| **按当前窗口拟合** | 本次请求、窗口及新的峰拟合结果 | 调用实际拟合处理器 |
| **重新拟合 TB / 计算 EC L2** | 新曲面 / 刻度参数及图 | 使用当前可用上游结果计算 |
| 读取设置中 **保存为新版本** | 可复用读取预设的新快照 | 不自动为全部数据重算 |
| 输入选择中 **应用** | 上游结果版本与所选范围 | 保存选择，待更新层稍后计算 |
| 输入选择中 **应用并更新** | 同样保存输入选择 | 按“更新范围”执行相关步骤 |

改窗后，先计算该峰，再更新相应的曲面或刻度。单纯切到下一层只是导航，不会自动执行该层。

配置预览中的 **更新范围** 会列出受影响文件与通道；保存后可用 **更新受影响层** 连续执行。更新沿当前依赖传播：固定 TB 包的 EC 保持其选择，跟随本任务 TB 的 EC 随新曲面更新。Co60 联合双峰按同通道整组更新，本底变化影响所有引用它的观测。

## 在工作台中找文件

1. 展开页面下方 **文件与运行记录**。
2. **产物文件** 列出当前层可用的文件；点击条目查看相应图或文件入口。
3. 切换到 **运行记录**，找到刚才的计算，核对处理层、文件 / 能线、通道和时间。
4. 记录下直接列出保存的文件名。展开 JSON 或图片文件名，可在工作台内查看预览。
5. 点击 **打开完整文件** 查看完整内容或保存文件。

JSON 预览会截取部分数组和较深结构，适合快速核对参数；完整数据以“打开完整文件”中的内容为准。PNG / JPG 在展开时加载。配置保存、窗口修订、TB 依赖选择等操作也会在记录中列出对应文件。

## 在服务器目录中找文件

个人工作区下每份任务的入口是：

```text
<workspace>/runs/<run_id>/
├── state.json       当前任务、所选配置、处理状态及引用
├── acquisition/     XML、profile 与分析 YAML 快照
├── inputs/          选定产品的引用、文件清单及适配输入
├── dependencies/    所选 TB 参数包快照
├── revisions/       窗口、屏蔽点和配置修订
├── peak-config/     源谱能线编辑记录
├── products/        当前任务的产品
└── jobs/            每次计算的记录、日志及产物
```

`run_id` 可从工作台任务标识或目录索引中找到。产品路径包含载荷编号；实际生成的文件名以运行记录为准。

新规范 L1 分析包的主要文件：

| 文件 | 用途 |
| --- | --- |
| `meta.json` | 输入、选段、曝光、处理配置及依赖 |
| `points.json` | 按物理通道组织的峰参数和误差 |
| `spectra.parquet` | 分箱谱、密度和误差等数组 |
| `fit.png`、`selection*.png` | 拟合和选段图 |

TB / EC L2 使用时间戳模型包。工作台为既有处理器同时维护兼容索引，因此磁盘路径里可能出现旧内部层号；操作时以界面层名、文件内容与运行记录对应关系为准。

## 比较修改前后的结果

在 TB L2 选择 **参数比较**，查看初始基线、当前任务和各参数变化；EC L2 的相应页签为 **刻度参数**。这些表比较当前任务与其导入的初始基线。

要保留两套独立处理方案，可分别创建或继续两份任务，固定各自预设版本、TB 包和处理范围，再切换比较。已有任务发布预设新版后仍使用自己的快照；要采用新版需主动切换。

比较时至少对齐以下四项：同一批观测、相同物理通道、相同 TB 参考条件，以及本次纳入的能线 / 工况。对比曲面 / 刻度残差时，再检查其峰位误差和屏蔽点是否相同。

## 重新打开与继续

关闭浏览器不会删除任务。重新进入工作台后，选择载荷和原任务；它会恢复已保存的结果、处理层、通道与文件位置。

在 **选择数据 / 产品** 中选择同一来源，可在“已有任务”里找到对应个人任务并点击 **继续**。切换任务是继续一份已有容器；重新点“创建任务并载入”会建立另一份容器。
