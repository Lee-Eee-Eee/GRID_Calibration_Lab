# 常见问题

遇到问题时先保留当前文件、通道和任务，展开 **文件与运行记录 → 运行记录** 找到该次任务。记录中的实际错误通常能指向要修改的那一项。连接和启动步骤见 [服务器部署](https://github.com/Lee-Eee-Eee/GRID_Calibration_Lab/wiki/Server-Setup)，目录与预设操作见 [数据、预设与任务](https://github.com/Lee-Eee-Eee/GRID_Calibration_Lab/wiki/Data-and-Presets)。

## 连接与目录

| 现象 | 处理方式 |
| --- | --- |
| 浏览器打不开工作台 | 检查服务器服务是否运行、本地 SSH 转发是否仍连接；使用部署时分配给自己的端口。 |
| SSH 断线后页面失去连接 | 重新建立隧道，再刷新原页面；已保存的配置和产品仍在服务器。 |
| 服务提示端口已占用 | 先确认是不是自己的服务已运行；另一成员的服务使用另一端口。 |
| 目录存在但扫描不到数据 | 检查填写的是服务器路径及载荷目录层级；进入读取设置检查子目录、文件规则或逐文件映射。 |
| 找到了文件，但创建时找不到唯一配置 | 在新建任务弹窗明确选择“读取配置”和版本，再创建；检查数据、产品目录各自关联的预设。 |
| 选择产品目录后不能重新解包 | 继续查看、复核已有产品；需要解包时，同时选择它对应的原始数据目录。 |
| 任务列表里有多个相近名称 | 先看载荷、配置版本和数据目录，再决定继续哪一份。名称是用途描述，实际配置以快照为准。 |

## 解包与 CRC

### 事件 / HK 未配对或配对有歧义

在 **解包与读取设置 → 文件与工况** 检查事件 / HK 正则的配对键 `key`，或直接检查逐文件映射中的两条路径。重新执行“预览与校验”，找到对应行后再解包。

若后续文件名不再包含温偏、通道或源名称，可使用逐文件映射填写这些信息。温偏来源还需在读取配置中明确选择；仅改变文件名表达式不会改变已经选定的 HK 工况读取方式。

### 全部事件 CRC 失败

核对事件 / HK XML、包标签、字节序和重复布局。14B / 15B 当前事件包为 584 字节、38 个事件、14 字节步长；旧 40 / 12 配置不能用于这批数据。10B 则有自己的 XML 和波形包布局，应采用对应载荷预设。

载入正确配置后，回到 L0 重新解包。谱区提供 **重新解包**、**重建此谱** 或 **重建此源** 时，也可使用该入口；源谱重建会包含该观测所需的本底和校正步骤。重建完成后再执行峰拟合。

### 改了 XML、字段或文件表，界面提示上游待更新

采用的新配置已保存，相关结果需要更新。先在 **预览与校验 → 更新范围** 查看文件、通道和起算层；保存后点击 **更新受影响层**。XML 或解包字段变化通常从相关 EXP/L0 开始，文件规则则按实际配对变化决定范围。

## 拟合与依赖

### 输入来源与更新范围

| 现象 | 处理方式 |
| --- | --- |
| 更换输入后仍显示旧曲线 | 输入选择已保存，相关计算待更新；点击“更新受影响层”，或回到当前层运行。 |
| 希望直接使用另一任务的曲面或刻度 | 在本层打开“结果 → 采用已有结果…”，选择对应结果包。 |
| “其他任务”没有目标结果 | 检查是否为当前工作区、同一物理载荷，以及该层是否已生成可用结果；也可将产品目录登记为数据来源。 |
| 只想换一个工况或通道 | 在输入“更换”侧栏展开“选择文件与通道”，再查看“更新范围”。 |
| 本任务 TB 重算后 EC 没有待更新 | 检查 EC 是否固定使用指定 TB 包；若要随本任务更新，在 TB 输入中选择“当前任务 → 跟随本任务 TB”。 |
| 所选结果已变化或不存在 | 重新打开输入选择侧栏，选择仍可用的具体结果版本。 |
| 源与本底记录了不同 TB 条件 | 选用同一目标 TB 校正条件下的输入，或回到 corr 更新这些观测。 |

查看运行记录中的 JSON 或图只预览文件；“采用已有结果”会改变本层使用的结果。完整步骤见[分层输入指南](https://github.com/Lee-Eee-Eee/GRID_Calibration_Lab/blob/feat/calibration-workbench/docs/layer_inputs.md)。

| 现象 | 先检查什么 | 怎样继续 |
| --- | --- | --- |
| 谱已显示但没有拟合参数 | 该文件、通道或新能线尚未拟合 | 设置窗口，点击“按当前窗口拟合” |
| 窗口无效或太窄 | 当前显示的 bin 宽、上下限及输入单位 | 扩大窗口，至少覆盖界面要求的 bin 数 |
| 自动选窗靠近暗区锁错峰 | 目标峰与暗噪声是否分开，能线 / 通道是否选对 | 拖窗手动拟合，或提供实测噪声上界、独立期望 ADC |
| 多能线源拟合第一峰失败 | 是否给出了目标峰窗口或独立中心锚 | 分别配置各能线，避免只按最高峰猜最低能线 |
| Co60 联合双峰提示窗口不含两个中心 | 当前窗口是否只剩一峰 | 扩展到容纳两个中心锚，再拟合；检查本次是否确实采用 doublet 配置 |
| 结果标为“疑似问题” | 主谱、背景、残差和峰位误差 | 可继续下游，必要时调整窗口 / 模型或人工屏蔽 |
| 塑料 CH3 显示模型待定 | 是否为 10B / 11B 的康普顿占优响应 | 可看谱和拖窗；该通道暂不执行高斯拟合，继续其他适用通道 |
| EC 提示未选择 TB 参数 | “TB L2 校正参数”是否已点“采用此版本” | 采用已有包或导入包，再运行 corr |
| EC 提示 TB 依赖变化或谱版本已更新 | 源、本底与峰拟合是否采用相同目标 TB 条件 | 对所需范围重新运行 corr → L1 → L2 |
| 全量标定提示上游范围不完整 | 之前是否只处理了一个代表文件或当前通道 | 使用上游“全部数据”入口完成相应范围，再汇总标定 |

“下一层”只切换页面。修改窗口后应先实际拟合，再运行曲面 / 刻度步骤。

## 图表与参数

### 低能点挤在一起

在 EC L2 的“能量刻度坐标”选择 **双对数坐标**。检查线性 ADC—能量形状时再切回“线性坐标”。局部谱的窗口和数值仍用 ADC 表示。

### 净谱中有负 bin

信号和本底独立归一化后相减，低计数区域可能出现负值。局部净谱与残差保留线性纵轴，按传播误差判断，不把负 bin 截成零来拟合。

### 刻度曲线两段之间有断点

当前 14B / 15B 低、高能段分别拟合，并在各自实测 ADC 范围绘图；段间留白是分段显示。可在“分析配置 → ec_l2.yaml”核对边界。

### 高能拟合仍有明显残差

从残差图点击对应点，先检查它的原谱、能线身份、窗口、峰位误差和 TB 依赖。例如 Co60 两个全能峰需要分别确认；不能只把第一个明显峰统一标成 1332.492 keV。若谱拟合合理而跨能区残差仍有结构，再检查 X / γ 源条件和能量关系模型。

### 预览中的 JSON 数组只显示一部分

预览面向快速核对，只显示部分数组及深层结构。点击 **打开完整文件** 查看全部内容。

## 一次操作部分完成或服务重启

批量任务的某个通道失败时，查看该通道的错误与谱；其他已完成通道的结果仍保留。修复后可以只重算对应点，随后更新 TB L2 或 EC L2。

刷新浏览器可继续跟踪运行中的任务。若服务器进程曾中断，运行记录会说明该次计算被中断；重新打开原任务，确认已生成文件和待更新层，再重新提交相应步骤。

向维护者反馈时，提供：任务名称 / run ID、载荷、处理层、工况或源文件、物理通道、能线、任务时间和运行记录中的错误。涉及峰选择时附主谱、窗口和残差截图，通常比仅提供一张状态截图更容易定位。
