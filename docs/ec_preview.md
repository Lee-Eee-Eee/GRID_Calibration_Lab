# 能量刻度预览

能量刻度总览默认使用双对数坐标，右上角可切换线性坐标，刷新后保留选择。残差图的能量轴随之切换，残差纵轴保持线性以显示正负偏差。点击实测点仍下钻对应通道和能线的真实谱。

`cali_proc@0.5` 的低、高能二次模型分别在各自参与拟合点的实测 ADC 范围绘制；段间留断点。预览不再根据外推后的预测能量判断应使用哪个分段。残差直接采用对应点的模型预测；分段间无预测的能线不被补成零。
