## 配置与计算

14B / 15B 的文件表和 `tb_l1.yaml`、`tb_l2.yaml`、`ec_l1.yaml`、`ec_l2.yaml` 已打包到 `resources/cali_proc/`，保留源提交及哈希。工作台可载入、编辑 YAML、另存预设和切换版本；试算冻结 XML、换算、文件配对、源能线及四份分析配置。

服务器确认文件表将 14B 指向旧原始目录 `14B15B/03`，15B 指向 `14B15B/02`，以 `source_mapping` 明确保存。已有本地试算继续使用自己的标签和配置。

- SCI 使用原生整数 `timestamp1 / 100 MHz`；HK 独立选择四通道偏压平台，不用 SCI 的时钟截取 HK。
- EC 分别使用信号、本底同一物理通道的首末事件跨度。X 射线按 `[1,2,3,0]` 选本底曝光文件，再选择原物理通道。
- TB 14B 记录全采集首末跨度；15B 按参考 `g15b/obs.py::with_tb_span(global_extrema=True)` 记录全 SCI 最小至最大计数跨度。原生顺序和间断诊断同时保留。15B YAML 的 first/last 描述与该代码行为存在差异，实际输出明确记录所用依据。
- 默认 4 ADC/bin；TB 保存 Counts/ADC，EC 保存 Counts/s/ADC。Gehrels 计数误差经曝光、bin 宽归一化后传播；拟合使用绝对误差、`scale_covar=False`。
- 背景、窗口、初值、边界、分段和参考条件来自对应配置。EC 能量按 ADC 误差进行固定能量锚的分段 ODR；分辨率按比例输出。

本轮修正了两个影响真实拟合的旧约束：TB 线性本底在 ADC=0 的截距可以为负；EC 的候选峰宽不再成为最终高斯宽度下限。EC 按参考模型先初始化目标峰，再用残差初始化背景，Co60 的伴随高斯保留独立分量；手动窗口和中心锚继续生效。

## 15B Co60 的物理复核

现行上游配置将约 `6682 / 7417 / 6737 / 7752 ADC` 的峰标为 1332.492 keV。用 Na22 511.004 与 Cs137 661.657 keV 的峰位估算，这些峰更接近 1173 keV；其右侧还有约 `7638 / 8494 / 7714 / 8858 ADC` 的峰。两峰关系与 Co60 双能线一致，提示该窗口可能对应 1173.228 keV。

因此，15B 本轮结果实现了参考配置的数值复现，但其 Co60 能线身份和高能标定仍须复核；高能 ODR 的约化 χ² 约为 212–365。确认两条能线及窗口后，可在现有多峰编辑器中保存为新预设版本并局部重算。本轮保留上游确认配置和该项证据。
