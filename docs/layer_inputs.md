# 分层输入、结果复用与局部更新

每份标定任务有自己的配置、输入选择、结果和日志，在顶部任务列表中继续处理。主图区上方的输入栏显示当前层使用的来源；需要换一份上游结果时，点击该行的输入选择框。

## 选择输入

1. 进入要计算的处理层，例如 TB L2。
2. 点击输入栏中 **TB L1 输入选择框**。
3. 在侧栏选择 **共享产品 / 当前任务 / 其他任务**。
4. 选择结果，核对生成时间、文件与通道覆盖；“文件与配置”可展开查看具体路径。
5. 默认使用整份输入。只替换部分输入时，展开 **选择文件与通道**，保留需要的文件与物理通道。
6. 查看 **更新范围**，点击 **应用** 保存选择，或 **应用并更新** 继续计算。

| 来源 | 使用方式 |
| --- | --- |
| 共享产品 | 从当前数据集登记的产品目录选择已有分层结果 |
| 当前任务 | 选择本任务已有结果版本，或点击“使用本任务上游结果”连接当前上游 |
| 其他任务 | 从当前工作区同一物理载荷的其他任务及其成功结果中选择 |

其他成员的个人产品也可通过 **选择数据 / 产品** 登记为产品目录，再从该来源选择分层结果。

共享产品和指定结果版本会保存具体输入引用。本任务上游采用新结果后，选择“使用本任务上游结果”的下游会进入待更新状态。

## 各层读取什么

本页使用 14B / 15B 新规范界面的层名。

| 当前层 | 输入栏选择的内容 |
| --- | --- |
| TB EXP/L0 | 原始事件与 HK；通过数据目录入口更换 |
| TB L1 | TB L0 |
| TB L2 | TB L1 峰参数与工况 |
| EC EXP/L0 | 信号、本底的原始事件与 HK；通过数据目录入口更换 |
| EC corr | EC L0，以及单独选择的 TB L2 参数包 |
| EC L1 | 校正后的信号与本底，即 corr 结果 |
| EC L2 | EC L1 能峰结果 |

EXP/L0 和 corr 按文件执行；谱峰、曲面及能量关系拟合支持选择物理通道。

例如，使用共享 TB L1 重新计算曲面，只需在 TB L2 选择这份输入，再运行本层。读取这些峰时沿用其实际生成配置，本次曲面计算采用任务当前的 TB L2 设置。

## 更换输入、采用结果与查看文件

| 操作 | 结果 |
| --- | --- |
| 输入选择框 | 改变本层读取的上游，本层和使用它的下游待更新 |
| **右上角 ⋯ → 采用已有结果…** | 直接将所选结果包用于本层，本层无需重新计算；使用它的下游按依赖更新 |
| **文件与运行记录** 中展开 JSON、图片或日志 | 查看已有文件，保持计算输入不变 |

采用已有结果按结果包操作。只选部分文件或通道的入口位于“更换输入”的 **选择文件与通道** 中。

只想比较两次分析时，可以切换顶部任务查看各自结果，或展开对应运行记录预览文件。决定将另一份结果用于后续计算时，再执行“采用已有结果”。

## EC 的 TB 参数

EC corr 有两条独立输入：**EC L0** 和 **TB L2**。

- 指定某份 TB 结果：点击 TB L2 输入选择框，选定版本并应用。之后修改本任务 TB 曲面不改变这个选择。
- 跟随本任务：进入“当前任务”，选择 **跟随本任务 TB**。本任务产生新 TB 结果后，EC corr 与使用它的下游待更新。
- 使用服务器上的其他 JSON：在选择侧栏点击 **导入 TB 参数包**，填写服务器路径并采用。

采用已经校正的 EC 输入时，保留它实际使用的 TB 依赖。若需要改用另一份 TB 参数，应回到 corr 重新校正相应范围，再更新峰拟合与能量关系。

## 修改配置后更新哪些层

在“解包与读取设置”修改配置后，点击 **预览与校验**。预览中的 **更新范围** 列出受影响的层、文件和通道。保存配置后，主区提供 **更新受影响层**，按依赖顺序执行这些步骤。

| 改动 | 更新起点 |
| --- | --- |
| XML、事件字段、包布局、通道映射或工程量换算 | 相关 EXP/L0，再更新使用它们的下游 |
| 文件匹配规则 | 比较实际配对；新增或替换输入从 EXP/L0 开始 |
| TB 选段、分箱、峰窗或谱背景模型 | 相关 TB L1，再更新对应通道 TB L2 |
| TB 屏蔽点、曲面模型或权重 | 对应通道 TB L2 |
| EC 的 TB 包、校正参考条件、选段或曝光设置 | 相关 corr，再更新 EC L1、L2 |
| EC 信号与本底配对 | 所需 corr 与相关 EC L1、L2 |
| EC 峰窗、中心锚、分箱、峰模型或新增能线 | 相关 EC L1，再更新对应通道 EC L2 |
| EC 屏蔽峰、分段边界、刻度或分辨率模型 | 对应通道 EC L2 |
| 任务名称、备注、图表坐标和显示范围 | 无需计算 |

范围沿当前选定的依赖传播。固定使用外部 TB L1 的曲面，不会因为本任务重新解包就自动换掉输入；固定 TB 包的 EC，也不会随另一份 TB 曲面重算而变化。

联合拟合以整组峰更新。例如 Co60 CH1 改窗后，该通道的两个联合峰和协方差一起更新，再更新 CH1 的 EC L2。本底变化会传播到所有实际引用它的观测。

## 个人目录与重开恢复

共享原始事件包保持在服务器原位，工作区通过软链接访问数据。每份任务保存在 `<workspace>/runs/<run_id>/`：

```text
<run_id>/
├── state.json       当前配置、输入选择与处理状态
├── acquisition/     XML、读取预设及分析 YAML 快照
├── inputs/          选定产品的引用、文件清单与适配输入
├── dependencies/    固定的 TB 参数包
├── revisions/       窗口、屏蔽点及输入选择修订
├── products/        本任务结果
└── jobs/            每次计算的输入记录、日志和产物
```

大表优先通过链接读取。原生 L0 按所选范围生成现有处理器需要的 Parquet 接口，必要本底会一起准备。关闭浏览器后重新选择原任务，可以继续已保存的输入与结果。

更多操作见 [成员 Wiki](https://github.com/Lee-Eee-Eee/GRID_Calibration_Lab/wiki)、[数据与预设](https://github.com/Lee-Eee-Eee/GRID_Calibration_Lab/wiki/Data-and-Presets)、[结果复核](https://github.com/Lee-Eee-Eee/GRID_Calibration_Lab/wiki/Review-and-Results)。
