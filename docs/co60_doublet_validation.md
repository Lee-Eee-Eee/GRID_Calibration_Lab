# 15B Co60 双峰复核与 EC 重算

2026-11-02，使用 GRID 服务器上的原始数据、同一 TB 校正包和 4 ADC/bin 分箱。

## 峰身份与谱拟合

原配置把左侧峰标为 1332.492 keV。Na22 511.004 keV、Cs137 661.657 keV 的实测峰位向高能外推，左、右峰分别约落在 1157–1164 和 1321–1329 keV，支持 Co60 的 1173.228 / 1332.492 keV 双线身份。

两个峰的尾部相互叠加；分别缩窗做单高斯会使中心偏移数十 ADC。新版在覆盖两峰的窗口中同时拟合两个高斯和线性连续本底，两个中心独立变化，按初始锚的中点分区保持身份，不约束能比。拟合沿用绝对计数误差和 `scale_covar=False`。

| 通道 | 1173.228 keV 中心 / ADC | 1332.492 keV 中心 / ADC | 联合 χ²ν |
| --- | ---: | ---: | ---: |
| CH0 | 6712.57 ± 4.63 | 7694.78 ± 5.86 | 0.909 |
| CH1 | 7439.92 ± 3.92 | 8524.26 ± 4.82 | 1.035 |
| CH2 | 6760.90 ± 3.74 | 7748.13 ± 4.57 | 0.883 |
| CH3 | 7768.73 ± 3.21 | 8893.35 ± 3.68 | 0.904 |

新版支持以下源配置，原单峰格式保持兼容：

```yaml
Co60:
  fit_mode: doublet
  background: lin
  fit_range: [[5800, 8500], [6449.6, 9452], [5858, 8585], [6722.2, 9851.5]]
  peaks:
    - energy_keV: 1173.228
      center_anchor: [6713, 7440, 6761, 7769]
    - energy_keV: 1332.492
      center_anchor: [7695, 8524, 7748, 8893]
```

该段位于 `analysis_config.ec_l1.source.Co60`；文件、HK、本底和曝光选择继续使用原条目。各能线还可提供独立的四通道 `fit_range`，工作台手动拖窗优先。联合窗口需要同时包含两个中心锚。

每条能线保存完整分量参数、参数误差、协方差、两中心的 2×2 协方差及共同 `fit_group`。两次目标峰切换得到相同总曲线。工作台与规范产物导入器均可重建伴峰和连续本底；该组合在规范点中以 `background: gaus+lin` 扩展保存，旧上游单背景绘图器需要增加此模型。
